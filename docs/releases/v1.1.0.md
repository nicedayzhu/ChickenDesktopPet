# CS2 小鸡桌宠 v1.1.0

Windows 实时 3D 桌宠。默认是 CS2 小鸡，支持切换鸡宠物、互动、检视和本地拍照。

## 新功能

- 新增普通鸡、波兰鸡、丝羽鸡及对应羽色，还有破壳蛋与完整蛋。外观和兼容动画在启动时从本机 CS2 资源中发现；游戏资源变化时保留默认回退逻辑。
- 新增鼠标悬停互动栏，可喂食、表演、睡觉/叫醒，也可选择坐下、惊慌、摇尾、跳舞、跳跃、踢腿、飞翔等兼容动作。
- 新增官方风格的检视与摄影棚：旋转、缩放、宠物命名、外观切换、背景选择、PNG 拍照和本地照片库。
- 精简右键菜单为 7 个入口；互动、照片、桌面设置和关于集中到子菜单，睡觉/叫醒按状态显示，桌面开关使用勾选状态。
- 补充作者信息、MIT 许可和第三方声明。历史 2D 版本源码继续保留在 `Pet/`。

## 修复与体验改进

- 修复其他鸡缺少动画，以及切换宠物后默认小鸡光照异常的问题。
- 改进羽毛透明覆盖，保留绒毛细节，修复亮色背景透亮缝隙和暗色背景矩形光晕。
- 为动画预先计算安全取景，播放过程中保持固定镜头，减少动作越界和模型忽大忽小。
- 改进检视窗口布局、标题及空白区域拖动、缩放按钮语义和鼠标旋转方向。

## 下载与运行

1. 下载 `ChickenDesktopPet3D-v1.1.0-win-x64.zip`。
2. 解压后运行 `ChickenDesktopPet3D.exe`。

运行要求：**Windows 10/11 x64**、本机已安装 **Counter-Strike 2** 和 **[.NET 10 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/download/dotnet/10.0)**。首次加载需要数秒。

发布包只包含一个 EXE，模型、材质、动画和官方互动图标从本机 CS2 安装中读取。若游戏无法自动定位，请将环境变量 `CHICK_CS2_VPK` 设为 `pak01_dir.vpk` 的绝对路径。

升级时退出旧版本，再替换 EXE。宠物选择和桌面设置保存在 `%APPDATA%\ChickenDesktopPet\settings3d.json`，照片保存在系统“图片”目录下的 `CS2 鸡桌宠/`。

## 使用提示

- 单击回应，双击表演，中键喂食，拖动移动，滚轮旋转。
- 悬停约半秒出现互动栏；右键打开菜单；检视窗口支持滚轮缩放和拖动宠物旋转。
- 各宠物的动作以当前游戏资源支持情况为准。完整蛋为静态外观。
- 名称和照片存储在本机，不连接 Steam 库存成长或照片服务。

发布附件中的 `SHA256SUMS.txt` 可用于核对下载包完整性。项目源代码按 MIT 开源，CS2 游戏内容的权利属于 Valve；第三方信息见 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)。
