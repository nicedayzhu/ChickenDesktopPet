# CS2 Chicken Desktop Pet v1.0.0

The initial release of a real-time 3D CS2 chick companion for your Windows desktop.

<img width="360" height="360" alt="CS2 chick desktop pet" src="https://github.com/user-attachments/assets/e6836540-813a-4b51-a119-101c075df53b" />

## Highlights

- A desktop chick rendered from your local CS2 models, materials, and animations.
- Click reactions, feeding, performances, sleep, and desktop roaming.
- Controls for pet size, rotation, staying on top, and power saving.
- A portable Windows x64 release with a single EXE.

## Requirements

- Windows 10 or 11, x64.
- Counter-Strike 2 installed locally.
- [.NET 10 Desktop Runtime for Windows x64](https://dotnet.microsoft.com/download/dotnet/10.0).

Game models, materials, and animations are read from your local CS2 installation.

## Getting Started

1. Download `ChickenDesktopPet3D-win-x64.zip` from the release assets.
2. Extract the archive and run `ChickenDesktopPet3D.exe`.
3. Allow a few seconds for the initial load.

If CS2 cannot be located automatically, set the `CHICK_CS2_VPK` environment variable to the absolute path of `pak01_dir.vpk`.

## Controls

- Single-click to react, double-click to perform, drag to move, and scroll to rotate.
- Right-click the pet or tray icon for feeding, sleep, roaming, and desktop settings.
- Settings are stored in `%APPDATA%\ChickenDesktopPet\settings3d.json`.
